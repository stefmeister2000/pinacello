Gebruik FRIENDS10 voor 10% korting op de producten in je eenmalige bestelling. Eén gebruik per klant, zonder minimumaantal. De code geldt niet voor abonnementen of verzendkosten. Vul de code zelf in bij het afrekenen en controleer het totaal vóór je betaalt.

Hoe krijgen we allebei 10% korting?

Deel FRIENDS10 met je vriend. Jullie plaatsen elk een eigen bestelling en vullen allebei deze code in bij het afrekenen.

Moeten we tegelijk bestellen?

Nee. Jullie kunnen op verschillende momenten bestellen. Dezelfde code werkt één keer per klant.

Moeten we elk twee flessen bestellen?

Nee. Er is geen minimumaantal flessen. Ieder kiest zelf wat hij of zij bestelt.

Hoe vaak kan ik de code gebruiken?

Je kunt FRIENDS10 één keer gebruiken. Je vriend kan dezelfde code ook één keer gebruiken voor een eigen bestelling.
